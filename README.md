# Starr Decor Luxe Showcase

Create a premium, elegant interior design website for a company called:

STARR DECOR LUXE

The website should feel like a high-end luxury interior design studio. Use the attached reference image as visual inspiration for the overall layout, typography, spacing, color palette, image placement, and luxury aesthetic, but do NOT copy the website exactly. Create an original design inspired by it.

BRAND STYLE:

- Luxury

- Elegant

- Warm

- Sophisticated

- Modern

- Feminine but professional

- High-end interior design

- Editorial/magazine-inspired

- Lots of clean whitespace

- Premium photography

- Subtle animations

- The website should feel like a $5,000+ professional interior design website

COLOR PALETTE:

- Warm ivory / cream backgrounds

- Soft beige

- Black / charcoal

- Warm taupe

- Subtle gold/champagne accents

- Avoid bright colors

- Use strong contrast for buttons and important sections

TYPOGRAPHY:

Use an elegant serif font for large headings and a clean modern sans-serif font for body text and navigation.

The typography should feel similar to luxury fashion/interior design magazines.

IMPORTANT:

Make the website feel custom-designed, not like a generic template.

Use strong visual hierarchy, generous whitespace, sophisticated typography, large photography, subtle animations, and editorial layouts.

Do not use excessive rounded cards, gradients, bright colors, or overly futuristic UI.

The final result should feel like a luxury interior design brand that could confidently charge thousands of dollars for its services.

Make all images and text easy to replace later when the client provides their real information, photos, logo, social links, and contact information.
